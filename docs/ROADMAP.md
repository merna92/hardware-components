# Roadmap

## Must Have

- Manual authentication.
- Role-based dashboards.
- Product catalog.
- Cart and checkout.
- Orders.
- PC build creation.
- Product comparison.
- Reviews.
- Wishlist.
- Support tickets.

## Should Have

- Recommendation requests and saved results.
- Compatibility warnings.
- Admin dashboard metrics.
- Notifications.

## Could Have

- Advanced recommendation scoring.
- Payment gateway integration.
- Email notifications.
- Product import from CSV.
